# Creatingly Interview Project
Project Brief – JavaScript Developer
Brief Description of Project:
Build a JavaScript module that:
1. Fetches an external HTML document from a given URL.
2. Parses the HTML safely.
3. Extracts: <br/>
  i) All unique tag names <br/>
 ii) Count of each tag
4. Sorts tags by: <br/>
 i) Highest frequency first
5. Displays them in a scrollable container.
6. Implements virtual scrolling (true virtualization): <br/>
 i) Only render visible rows <br/>
 ii) Do NOT append all elements to DOM<br/>
 iii) Must handle 10,000+ items efficiently
7. Add a search filter that works without re-rendering everything. <br/>
URL: https://api.allorigins.win/raw?url=https://example.com
